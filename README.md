## 🌟 Executive Overview

**SupiriStudio PRO** (`https://studio.prasatek.lk`) is an ultra-advanced, 100% free commercial-grade AI media editing suite designed and developed by **PrasaTek System Solutions**. Built for content creators, e-commerce sellers (Daraz, Facebook Marketplace, Shopify, WooCommerce), graphic designers, and everyday users, SupiriStudio PRO delivers studio-quality tools directly in the browser with **zero subscription fees, zero login walls, and zero forced watermarks**.

Powered by a lightweight, high-performance Python FastAPI backend paired with deep learning ONNX segmentation models, OpenCV computer vision algorithms, and FFmpeg video processing pipelines, SupiriStudio PRO provides professional-grade results while strictly honoring cloud RAM limits (< 500 MB footprint) and protecting client privacy.

### 1. ✂️ AI BG & Product Studio PRO
*Alternative to Photoroom, remove.bg, and Clipping Magic.*
- **Deep Learning AI Segmentation:** Uses `rembg` powered by ONNX Runtime (`u2netp` and `u2net_human_seg`) with singleton session caching for instant background extraction in under 2 seconds.
- **Dual AI Modes:**
  - `🤖 Auto AI General:` Razor-sharp cutouts for e-commerce products, electronics, shoes, cars, pets, and logos.
  - `👤 Portrait Hair Pro:` Fine-tuned boundary refinement for human hair, complex fabrics, and transparent edges with alpha matting.
- **Interactive Manual Refinement Toolbar:**
  - `🟢 Restore Brush (මැකුණු කොටස් ආපහු ගන්න):` Recover accidentally erased parts of the subject.
  - `🔴 Erase Brush (අනවශ්ය කොටස් මකන්න):` Manually paint over unwanted background chunks.
  - `🪄 Magic Color Eraser:` 1-click tolerance-based flood fill eraser for studio backdrops.
  - `🔍 Zoom & Pan:` High-precision pixel control with infinite canvas manipulation.
- **Commercial Product Staging:**
  - Solid studio backdrops, linear/radial gradients, and custom photo backdrop uploads.
  - **3D Drop Shadows:** Customizable blur radius, X/Y distance offsets, and opacity.
  - **White Outline Sticker Stroke:** Professional e-commerce highlight borders.

## 💻 Local Setup & Development Instructions

### Prerequisites
- Python 3.10+ (Recommended: 3.11)
- Git
- Modern Web Browser (Chrome, Edge, Firefox, Safari)

### 1. Clone the Repository
```bash
git clone https://github.com/PRASA8591/SupiriStudio-PRO.git
cd SupiriStudio-PRO
```

### 2. Create and Activate a Virtual Environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run the Local Development Server
```bash
python -m uvicorn app.py:app --host 0.0.0.0 --port 7860 --reload
```
Open [http://localhost:7860](http://localhost:7860) in your browser.

## 🐳 Docker & Cloud Deployment Guide

### Build & Run with Docker
A production-ready `Dockerfile` with Ubuntu 22.04 base, system OpenCV dependencies, and FFmpeg is included:

```bash
# Build the Docker image
docker build -t supiristudio-pro:latest .

# Run the container
docker run -d -p 7860:7860 --name supiristudio supiristudio-pro:latest
```
Access the application at [http://localhost:7860](http://localhost:7860).

### Deploying to Render.com / Hugging Face Spaces
1. **Repository:** Connect your GitHub repo.
2. **Environment:** Docker or Python 3.11.
3. **Build Command:** `pip install -r requirements.txt`
